# Project Zed: Virtual Sticky Notes

## 📝 Project Overview

**Virtual Sticky Notes** is an AI-assisted web application that transforms your browser into a creative digital canvas. This interactive drawing and note-taking tool allows users to sketch, write, and express themselves with various tools including brushes, spray paint, erasers, and text capabilities.

This project represents the culmination of skills developed throughout WRIT 40363, building upon foundations from Projects 1-3 and pushing beyond with AI collaboration to implement advanced features and techniques.

## 🎯 Project Context

This is **Project Zed**, the final project for WRIT 40363: Coding for Communicators at TCU. The assignment focuses on:

- **Upskilling** techniques learned in previous projects
- **AI-Assisted Development** using tools like Claude/ChatGPT/Copilot
- **Ambitious experimentation** with new web technologies
- **Deep learning and reflection** over perfection
- **Documentation** of the AI collaboration process

The goal is to demonstrate growth as a developer by attempting something challenging with AI as a development partner, documenting both successes and struggles along the way.

## 🛠️ Setup Instructions

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- No installation or dependencies required!

### Local Setup

1. **Clone or download this repository:**
   ```bash
   git clone https://github.com/amvaldeswriter/writ40363-portfolio-valdes.git
   cd writ40363-portfolio-valdes/projects/project4-zed
   ```

2. **Open in browser:**
   - Simply open `art.html` in your web browser
   - Or use a local server (optional):
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Then visit: http://localhost:8000/art.html
     ```

3. **Start creating!**
   - Select a tool from the toolbar
   - Choose your color
   - Draw on the canvas
   - Save your artwork when finished

## 🎨 How to Use

1. **Choose a Tool:** Click on any tool button (Pencil, Eraser, Spray Can, or Text)
2. **Select a Color:** Use the color picker to choose your drawing color
3. **Adjust Size:** Use the size slider to change brush/eraser thickness
4. **Draw:** Click and drag on the canvas to create your artwork
5. **Add Text:** Select the text tool, click on canvas, and type
6. **Save:** Click "Save Image" to download your creation as a PNG
7. **Clear:** Use "Clear Canvas" to start fresh
8. **Undo:** Click "Undo" to remove the last action
