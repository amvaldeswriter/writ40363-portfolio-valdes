This past summer, I interned with Wells Fargo in their Online Fraud Detection department. A large part of my job was to l document the facets of the industry, company, and line of business that I learned about through one-on-one conversations and informational interviews. With this in mind, the new Microsoft sticky notes application became my most used laptop application. The sticky notes I created included reminders, schedules, ideas, and conversations. Name it, I surely had a sticky note about it. An aspect of the Microsoft application that I appreciated was the almost ‘gallery’ that they were compiled in. On my laptop this looked like a column of sticky notes that I could scroll through based on the date they were created, and you can see a similar feature included in my Project Zed. Yet, I felt there was something missing from this application: the ability to easily export the sticky notes as files (PDF, JPEG, PNG, SVG). Instead, I had to copy the information into a separate document to be able to share it. 

As for the upskilling from Projects 1-3, Claude Sonnet 4.5 helped me to create a foundational platform that was quite similar to Project 2 as I felt this project was most similar to the Project Zed I envisioned. From here, I was able to upskill my CSS design by moving from flat value colors to :root color variables. This feature was used in Project 3, but I was then able to implement the same feature in Project Zed in combination with new responsive design features. In Project 2, I had media queries that allowed for the page layout to adjust as the browser moved. In Project Zed, the toolbar, gallery, modal, and export menu included special handling for smaller devices using both min and max px as well as percentages for minimum width. 

As for the use of AI in my development process, I had a very clear vision for how I wanted this platform to look and this platform to feel. With this in mind, AI was a valuable tool in creating and modifying code and bringing my vision to life. In the absence of AI, a developer has to create the files, write the code, test the code, and debug the files. This process may be repeated many times before a webpage or project reaches its final accessible state. When thinking critically about how AI changed my development process, the steps looked more like: write AI prompts, examine the webpage based on the prompts, rewrite AI prompts to enhance the webpage development, ask AI to debug and reorganize code. The process of writing AI prompts may take several attempts before the webpage looks and functions in the desired manner, but the use of AI may also help web developers to upskill. AI was able to create features that I am yet to learn about on my own time. After reviewing the code AI created, I am able to enhance my skills as a web developer and apply this code to future projects. 

In using AI as the primary tool for web development in Project Zed, I was surprised about how much of the code I was able to understand after reviewing it. Additionally, I found myself deleting lines of code to see how the webpage would change to better understand the features Claude Sonnet 4.5 created. When I think about what I would do differently, I may have used different types of AI to see how they compare when given the same prompt. For the entirety of Project Zed I used Claude Sonnet 4.5. I likely did this as I did not want to mess with the progress I was making. Additionally, I think I would have prompted AI to use the ai_collboration_log.md file with every AI prompt. This was an error on my part as the web developer, and now my ai_collboration_log.md file is incomplete. Rather than starting the project over, I corrected my error and began having AI write in the file to ensure that I could reference my prompting as much as possible. 

The shift of my confidence as a web developer is extreme. With the help of AI, I was able to create this Project Zed with only one semester of experience using any web development styles or platforms. I suppose this speaks to the power of AI and the power of useful prompting. I am really grateful to have had the opportunity to take this class and learn these skills.
